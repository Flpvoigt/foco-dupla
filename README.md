# Foco em Dupla

Um cronômetro Pomodoro simples, feito com HTML, CSS e JavaScript puro.

## Como usar

Abra `index.html` no navegador, escolha o tempo e clique em **Iniciar**.

## Recursos

- ciclos de foco e pausa;
- contador de sessões concluídas;
- botão para reiniciar;
- dados salvos no navegador.

## Colaboração

Projeto criado para praticar desenvolvimento colaborativo com Git e GitHub.
